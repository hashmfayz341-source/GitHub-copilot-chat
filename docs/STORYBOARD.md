# Storyboard — "Introduction to Anatomy" (motion-graphics lecture)

Source: *Lecture 1 — Introduction to Anatomy, Anatomy & Embryology* (26 slides).
Format: 1920×1080 · 30 fps · ≈12 min · narration by Kokoro neural TTS (`af_heart`).
Times are taken from `src/video/timing.json` (scene-relative seconds; see `docs/NARRATION.md` for every beat).

**Visual identity ("Lumen").** Deep-slate stage with a faint drifting measurement grid; an ivory
capsule-mannequin with dark shorts and hair (same proportions in 2D SVG and 3D); strict colour code —
blue = coronal / anterior–posterior, coral = sagittal / medial–lateral / right–left, green = transverse /
superior–inferior, amber = movement & attention, violet = rotation axis. Manrope (display) + Inter (labels).
Terms are revealed *after* the viewer has seen the concept happen.

**Story arc.** Hook (a real ambiguity) → why a shared language → what anatomy is → roadmap →
position → planes → direction → depth → movement → clinical case → retrieval quiz → summary.
Slide order was reorganised (e.g. cranial/caudal moved next to proximal/distal; elevation/depression grouped
with protraction/retraction; anatomical position re-used to introduce supination).
